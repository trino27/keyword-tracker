# AGENTS.md

The entry point for anyone — person or agent — working in this repository. It routes; the
rules themselves live in the trees it points to. `CLAUDE.md` imports this file.

## What this is

An SEO keyword tracker for a marketing agency: a user signs in, sees the crawled blog pages
of their clients' websites with each page's likely keywords, SEO issues and latest rank
position, opens a page to see its position history, and adds a client whose sitemap is then
crawled. Positions are generated by the seed script; pages and keywords come from the live
sites. Data is stored in UTC; the user is in Toronto.

## Commands

```bash
pnpm install                 # once
cp .env.example .env         # once; placeholder values only

docker compose up -d --build # the whole stack at http://localhost:8080

pnpm dev:db                  # Postgres only, for local development
pnpm db:migrate              # apply migrations
pnpm dev:be                  # API on :3000
pnpm dev:fe                  # SPA on :5173, proxies /api to :3000

pnpm lint && pnpm typecheck && pnpm test   # what pre-push and CI run
```

## Rules that are not optional

- **Branches and commits:** never commit on `main` (the pre-commit hook refuses); branch names
  and commit style are in [`skills/claude-workflow`](skills/claude-workflow/SKILL.md). Commit
  in small logical steps.
- **Schema changes:** edit the schema in `be/src/persistence/schema/tables/`, run
  `pnpm db:generate`, read the generated SQL, then `pnpm db:migrate`. Never hand-write or
  hand-edit a migration or `drizzle/meta/_journal.json`, never use `drizzle-kit push`.
- **Docker volumes:** never pass `-v` / `--volumes` to `docker compose down` and never prune
  volumes — that deletes the database.
- **Secrets:** only `.env.example` with placeholders is committed; `.env` stays local.
- **Data isolation:** every query over a user's data is scoped to that user in the query
  itself. A user must not reach another user's data by any route, including a changed id.
